### 2.1 Unicode Standard

Unicode 标准定义了世界上所有字符的编码，它将每个字符都映射到一个唯一的**码点（Code Point）**，即一个整数。

它可以看作是一个巨大的字典，给世界上每个字符都发了一张身份证 ID。比如：
- 汉字 `中` 的 ID 是 20013
- 英文字母 `a` 的 ID 是 97

这个数字只定义了唯一性，并没有定义在计算机中的存储方式，这就引申出了另一个话题——**编码**。

> Problem (unicode1): Understanding Unicode (1 point)
>
> (a) `chr(0)` 返回什么 Unicode 字符？
>
> 答：空字符（NUL character）
>
> (b) `__repr__()` 和 `print()` 的显示有什么不同？
>
> 答：`__repr__()` 返回转义表示形式（如 `'\\x00'`），而 `print()` 打印实际显示效果（通常不可见）。
>
> (c) 当字符串中包含 `chr(0)` 时会发生什么？
>
> ```python
> >>> chr(0)
> >>> print(chr(0))
> >>> "this is a test" + chr(0) + "string"
> >>> print("this is a test" + chr(0) + "string")
> ```
>
> 答：`chr(0)` 是空字符，在字符串中不会显示任何内容，但它确实存在于字符串中。

### 2.2 Encoding

目前针对 Unicode 标准，主要有三种编码方式：

| 编码方式 | 类型 | 说明 |
|---------|------|------|
| UTF-8 | 变长编码 | 码点 ≤127 使用 1 字节，>127 使用 2-4 字节 |
| UTF-16 | 定长编码 | 码点 ≤65535 使用 2 字节，>65535 使用 4 字节 |
| UTF-32 | 定长编码 | 不管码点是多少都使用 4 字节 |

注意：UTF-16 和 UTF-32 都有字节序问题（大端序/小端序）。

UTF-8 没有字节序问题，因为它的字节本身就包含了字节序信息：

```
0xxxxxxx                              (1 字节)
110xxxxx 10xxxxxx                     (2 字节)
1110xxxx 10xxxxxx 10xxxxxx            (3 字节)
11110xxx 10xxxxxx 10xxxxxx 10xxxxxx   (4 字节)
```

字节头部的 `0`、`110`、`1110`、`11110` 标识了字节数，自然不存在字节序问题。

> Problem (unicode2): Unicode Encodings (3 points)
>
> (a) 为什么更倾向于使用 UTF-8 编码来训练 tokenizer？
>
> 答：1. 空间效率更高，对于常见的 ASCII 字符只需 1 字节；2. 无字节序问题，而 UTF-16 和 UTF-32 都需要处理大小端问题
>
> (b) 下面的 UTF-8 解码函数为什么是错误的？
>
> ```python
> def decode_utf8_bytes_to_str_wrong(bytestring: bytes):
>     return "".join([bytes([b]).decode("utf-8") for b in bytestring])
>
> >>> decode_utf8_bytes_to_str_wrong("hello".encode("utf-8"))
> 'hello'
> ```
>
> 答：对于编码后只占 1 个字节的字符，这样解码是正确的。但对于编码后占多个字节的字符（如中文），它会尝试将每个字节单独解码，从而导致 `UnicodeDecodeError`。
>
> (c) 给出一个不能解码为任何 Unicode 字符的两字节序列。
>
> ```python
> print(b"\xc0\x80".decode("utf-8"))  # 会抛出 UnicodeDecodeError
> ```
>
> 这也解释了为什么 UTF-8 不存在字节序问题——它的字节本身就包含了字节序信息，一旦没有按照预期解码，就会导致错误，而不是生成错误的解码结果。


### 2.3 Subword Tokenization
使用byte-level的tokenizer，虽然能缓解词汇表OOV的问题，但把文本按字节级切分会导致输入序列过长（但是embedding的参数量会小）

这个问题很好理解，比如Apple，如果这个按照词意分割，那么它的token就是`apple`，但如果按照字节，那么它的token就是`a`、`p`、`p`、`l`、`e`，这样输入序列就变成了5个token，长度是原来的5倍。

attention层的复杂度是n方，n过长就会导致计算爆炸。

而subword tokenizer就是介于两者之间的，它将文本按字节切分，然后对切分后的字节序列进行subword切分，这样就能解决输入序列过长的问题，同时也能缓解OOV问题。

基于BPE实现的subword tokenizer，就叫做BPE分词器，这也是本次assigment要实现的一个内容。

### 2.4 BPE Tokenizer Training

**Vocabulary initialzation**：本assigment训练的是byte-level的BPE tokenizer，所以初始的词汇表大小是256，这对应了一个字节所能表示的范围。

**Pre-Tokenization**：有了初始词汇表，理论上是可以开始统计不同相邻字节的频率，然后对高频字节对进行合并，但是这里存在一个问题，那就是直接对语料库进行遍历的计算开销是非常大的（每次合并一对字节（比如 b'o'+ b'g'→ b'og'），你都需要重新扫描整个语料库，看看这个新字节对出现在哪里。），而且还会遇到一些特殊的问题。

例如：dog!和dog?，这里仅仅存在标点符号的不同，但是如果直接进行统计，就会产生两种截然不同的token IDs。

为了解决这些问题，可以使用预分词。

我们先对文本进行一次粗粒度的切分（预分词），然后利用这些预分词的出现频率，来快速统计“字符对”或“字节对”的出现次数，从而避免每次合并时都去扫描整个语料库，大大提升效率。

而且统计频率时，可以直接统计预分词的出现频率，而不需要统计每个字符的出现频率，因为预分词的出现频率，就代表了每个字符的出现频率。

例如“text”这个单词，统计t e出现的频率时，可以直接把text的数量加到t和e的频率上，而不需要单独统计t和e的出现频率。

原始的BPE实现是使用空格作为预分词，这太简单了，在本asigment中，会使用基于正则表达式的方法：

> ```python
> import regex as re
> PAT = r"""'(?:[sdmt]|ll|ve|re)| ?\p{L}+| ?\p{N}+| ?[^\s\p{L}\p{N}]+|\s+(?!\S)|\s+"""
> re.findall(PAT, "some text that i'll pre-tokenize")
> ```

| 正则 | 用途  |
|---------|------|
| (?:[sdmt]|ll|ve|re) | 匹配ll、ve、re，都是英语常见的简化写法 | 
| ?\p{L}+ | 匹配一个可选空格 + 一个或多个字母（支持多语言，如英文、中文） |
| ?\p{N}+ | 匹配一个可选空格 + 一个或多个数字（如 123, 456） | 
| ?[^\s\p{L}\p{N}]+| 匹配一个可选空格 + 一个或多个符号（如标点 !, ..., @#$） |
| \s+(?!\S) | 匹配末尾的空白（如行尾空格），用于保留格式 |
| \s+ | 匹配其他空白字符（如普通空格、换行），但通常会被前一项抢先匹配 |

这里需要注意，实际操作时要避免使用re.findall()，因为它会一次性返回所有匹配结果，语料库很大的话会占用大量内存，应该使用re.finditer()，每次返回一个匹配结果。

**Compute BPE merges**：有了预分词后，就可以正式利用BPE来做合并了，这里为了方便，不考虑跨词合并，并且相同词频的前提下，会采用字典序较大的对进行合并。

**Special tokens**：一些字符串（例如 <|endoftext|>）被用来编码元数据，我们希望将它们视为‘特殊 token’，永远不被拆分。

在生成文本时（比如聊天机器人回复），模型会不断预测下一个 token。当它输出 <|endoftext|>这个 token 时，就知道应该停止了。所以这个特殊token必须加入词汇表分配一个固定的ID，如果它也被拆分(["<|", "end", "of", "text", "|>", "]"])，那么模型就不知道什么时候该停止了。

```python
import os
import multiprocessing
from functools import partial
import regex as re
from cs336_basics.pretokenization_example import find_chunk_boundaries

PAT = r"""'(?:[sdmt]|ll|ve|re)| ?\p{L}+| ?\p{N}+| ?[^\s\p{L}\p{N}]+|\s+(?!\S)|\s+"""


def run_train_bpe(
    input_path: str | os.PathLike,
    vocab_size: int,
    special_tokens: list[str],
    **kwargs,
) -> tuple[dict[int, bytes], list[tuple[bytes, bytes]]]:
    """tuple[dict[int, bytes], list[tuple[bytes, bytes]]]:
    dict是vocab词汇表, list是merges列表"""

    # 预分词
    pre_tokenize_list = pre_tokenize(input_path, special_tokens)

    # 将特殊token转换为bytes集合，用于跳过
    special_token_set = set(special_tokens)

    # 将预分词列表转换为字节列表
    # 这里每个元素应该是 bytes 类型，而不是单个整数
    word_freq = {}
    for word in pre_tokenize_list:
        # 跳过特殊token，它们不参与BPE合并
        if word in special_token_set:
            continue
        # 将每个字符转换为单字节的 bytes 对象
        word_bytes = tuple(bytes([b]) for b in word.encode("utf-8"))
        word_freq[word_bytes] = word_freq.get(word_bytes, 0) + 1

    # 初始化词汇表(256个字节范围加上特殊token)
    vocab = {i: bytes([i]) for i in range(256)}
    for token in special_tokens:
        token_bytes = token.encode("utf-8")
        if token_bytes not in vocab.values():
            vocab[len(vocab)] = token_bytes

    merges = []

    # 初始化 pair_freq，只统计一次
    pair_freq = count_pair_frequencies(word_freq)

    # 下面是BPE算法的核心逻辑，loop的退出条件是vocab_size
    while len(vocab) < vocab_size:
        if not pair_freq:
            break

        # 1.根据频次找到最佳对进行BPE合并，如果频率相同，合并字典序更大的对
        best_pair = find_best_pair(pair_freq)
        if best_pair is None:
            break

        new_token = best_pair[0] + best_pair[1]
        vocab[len(vocab)] = new_token
        merges.append(best_pair)

        # 2.更新word_freq 和 pair_freq（增量更新）
        update_word_freq_and_pair_freq(word_freq, pair_freq, best_pair)

    return vocab, merges


def update_word_freq_and_pair_freq(
    word_freq: dict[tuple[bytes, ...], int],
    pair_freq: dict[tuple[bytes, bytes], int],
    best_pair: tuple[bytes, bytes],
) -> None:
    """更新word_freq和pair_freq（增量更新）"""
    new_token = best_pair[0] + best_pair[1]

    # 找出所有包含 best_pair 的 word
    words_to_update = []
    for word, freq in word_freq.items():
        for i in range(len(word) - 1):
            if word[i] == best_pair[0] and word[i + 1] == best_pair[1]:
                words_to_update.append((word, freq))
                break

    # 删除被合并的pair
    if best_pair in pair_freq:
        del pair_freq[best_pair]

    for word, freq in words_to_update:
        # 从 word_freq 中删除旧的 word
        del word_freq[word]

        # 先减去旧word的pair频次
        for i in range(len(word) - 1):
            pair = (word[i], word[i + 1])
            if pair in pair_freq:
                pair_freq[pair] -= freq
                if pair_freq[pair] <= 0:
                    del pair_freq[pair]

        # 构建新的 word
        new_word = []
        i = 0
        while i < len(word):
            if (
                i < len(word) - 1
                and word[i] == best_pair[0]
                and word[i + 1] == best_pair[1]
            ):
                new_word.append(new_token)
                i += 2
            else:
                new_word.append(word[i])
                i += 1

        new_word_tuple = tuple(new_word)

        # 添加新word的pair频次
        for i in range(len(new_word_tuple) - 1):
            pair = (new_word_tuple[i], new_word_tuple[i + 1])
            pair_freq[pair] = pair_freq.get(pair, 0) + freq

        # 更新 word_freq
        word_freq[new_word_tuple] = word_freq.get(new_word_tuple, 0) + freq


def count_pair_frequencies(
    word_freq: dict[tuple[bytes, ...], int],
) -> dict[tuple[bytes, bytes], int]:
    """统计预分词的频次"""
    pair_freq = {}
    for word, freq in word_freq.items():
        for i in range(len(word) - 1):
            pair = (word[i], word[i + 1])
            pair_freq[pair] = pair_freq.get(pair, 0) + freq
    return pair_freq


def find_best_pair(
    pair_freq: dict[tuple[bytes, bytes], int],
) -> tuple[bytes, bytes] | None:
    """根据频次进行BPE合并，如果频率相同，合并字典序更大的对"""
    if not pair_freq:
        return None
    best_pair = None
    max_freq = -1
    for pair, freq in pair_freq.items():
        if freq > max_freq or (freq == max_freq and pair > best_pair):
            best_pair = pair
            max_freq = freq
    return best_pair


def pre_tokenize(input_path: str, special_tokens: list[str]) -> list[str]:
    """对文本块进行预分词，返回预分词列表"""

    # 预分词阶段可以并行处理
    task = []
    with open(input_path, "rb") as f:
        num_processes = os.cpu_count() or 4
        boundaries = find_chunk_boundaries(f, num_processes, b"<|endoftext|>")

        for start, end in zip(boundaries[:-1], boundaries[1:]):
            f.seek(start)
            chunk = f.read(end - start).decode("utf-8", errors="ignore")
            task.append(chunk)

    num_processes = os.cpu_count() or 4
    with multiprocessing.Pool(processes=num_processes) as pool:
        # 使用 partial 来绑定 special_tokens 参数
        worker = partial(_pre_tokenizer_worker, special_tokens=special_tokens)
        results = pool.map(worker, task)

    # 合并所有结果
    pre_tokenize_list = []
    for res in results:
        pre_tokenize_list.extend(res)
    return pre_tokenize_list


def _pre_tokenizer_worker(chunk: str, special_tokens: list[str]) -> list[str]:
    """对文本块进行预分词，返回预分词列表"""
    if not chunk:
        return []

    result = []

    # 如果没有特殊token，直接用正则分词
    if not special_tokens:
        return re.findall(PAT, chunk)

    # 构建特殊token的正则模式，用于分割文本
    # 需要转义特殊token中的正则特殊字符
    escaped_tokens = [re.escape(token) for token in special_tokens]
    special_pattern = "|".join(escaped_tokens)

    # 使用正则分割，保留分隔符（特殊token）
    parts = re.split(f"({special_pattern})", chunk)

    special_token_set = set(special_tokens)
    for part in parts:
        if not part:
            continue
        if part in special_token_set:
            # 特殊token直接加入结果
            result.append(part)
        else:
            # 非特殊token部分用正则分词
            tokens = re.findall(PAT, part)
            result.extend(tokens)

    return result

from kilo_inplements.bpe_tokenizer_train import run_train_bpe
import pickle
import json
import time
import tracemalloc


def train_bpe_tinystories(tinystories_path, output_path):
    vocab_size = 10000  # 设置词汇表大小
    special_tokens = ["<|endoftext|>"]

    # 开始内存追踪
    tracemalloc.start()
    start_time = time.time()

    vocab, merges = run_train_bpe(
        input_path=tinystories_path,
        vocab_size=vocab_size,
        special_tokens=special_tokens,
    )

    # 记录训练时间和内存
    end_time = time.time()
    current_mem, peak_mem = tracemalloc.get_traced_memory()
    tracemalloc.stop()

    training_time_seconds = end_time - start_time
    training_time_minutes = training_time_seconds / 60
    peak_memory_gb = peak_mem / (1024 ** 3)

    # 将结果保存到输出路径
    with open(output_path, "wb") as f:
        pickle.dump((vocab, merges), f)

    # 统计信息
    # 找出最长的token
    longest_token = max(vocab.values(), key=len)
    longest_token_id = [k for k, v in vocab.items() if v == longest_token][0]

    # 尝试解码最长token
    try:
        longest_token_decoded = longest_token.decode("utf-8")
    except:
        longest_token_decoded = str(longest_token)

    # 检查特殊token
    endoftext_bytes = "<|endoftext|>".encode("utf-8")
    endoftext_id = None
    for token_id, token_bytes in vocab.items():
        if token_bytes == endoftext_bytes:
            endoftext_id = token_id
            break

    # 获取最长的10个tokens
    sorted_tokens = sorted(vocab.items(), key=lambda x: len(x[1]), reverse=True)[:10]
    top_10_longest = []
    for token_id, token_bytes in sorted_tokens:
        try:
            decoded = token_bytes.decode("utf-8")
        except:
            decoded = str(token_bytes)
        top_10_longest.append({
            "id": token_id,
            "token": decoded,
            "length_bytes": len(token_bytes)
        })

    # 构建统计信息
    stats = {
        "training_time_seconds": round(training_time_seconds, 2),
        "training_time_minutes": round(training_time_minutes, 2),
        "peak_memory_bytes": peak_mem,
        "peak_memory_gb": round(peak_memory_gb, 4),
        "vocab_size": len(vocab),
        "num_merges": len(merges),
        "longest_token": {
            "id": longest_token_id,
            "token": longest_token_decoded,
            "length_bytes": len(longest_token)
        },
        "top_10_longest_tokens": top_10_longest,
        "special_token_endoftext_id": endoftext_id,
        "input_file": str(tinystories_path),
        "output_file": str(output_path)
    }

    # 输出统计信息到JSON文件
    stats_output_path = output_path.replace(".pkl", "_stats.json")
    with open(stats_output_path, "w", encoding="utf-8") as f:
        json.dump(stats, f, ensure_ascii=False, indent=2)

    # 打印统计信息
    print("\n" + "=" * 50)
    print("BPE训练统计信息")
    print("=" * 50)
    print(f"训练时间: {training_time_seconds:.2f} 秒 ({training_time_minutes:.2f} 分钟)")
    print(f"峰值内存: {peak_memory_gb:.4f} GB")
    print(f"词汇表大小: {len(vocab)}")
    print(f"合并操作数: {len(merges)}")
    print(f"\n最长token:")
    print(f"  ID: {longest_token_id}")
    print(f"  内容: {repr(longest_token_decoded)}")
    print(f"  长度: {len(longest_token)} 字节")
    print(f"\n<|endoftext|> token ID: {endoftext_id}")
    print(f"\n统计信息已保存到: {stats_output_path}")
    print("=" * 50)

    return vocab, merges, stats

### 2.6 BPE Tokenizer:Encoding and Decoding
上个部分我们实现了训练BPE分词器，可以将文本转换成词汇表和合并列表。

这部分我们要更进一步，能够利用这些词汇表和合并列表，去将文本编码成token IDs，或者从token IDs解码成文本。

#### 2.6.1 Encoding text
这个阶段实际上和BPE训练很相似，只是不需要统计词频。

首先进行预分词，这里步骤完全一样，将text按照正则去拆分成单词列表。

下一步是遍历每个单词，根据合并列表，将优先级最高的合并操作应用到单词上，直到单词不再能被合并为止。

最后就是借助反向词汇表（因为词汇表是id->token的映射），将合并后的token列表转换成id列表。

#### 2.6.2 Decoding text
这一步更简单，只要遍历id列表，根据词汇表，将id转换成token，然后拼接起来就可以了。

```python
import json
from typing import Iterable, Iterator
from kilo_inplements.bpe_tokenizer_train import _pre_tokenizer_worker


class Tokenizer:
    def __init__(
        self,
        vocab: dict[int, bytes],
        merges: list[tuple[bytes, bytes]],
        special_tokens: list[str] = None,
    ):
        if special_tokens is not None:
            for token in special_tokens:
                token_bytes = token.encode("utf-8")
                if token_bytes not in vocab.values():
                    vocab[len(vocab)] = token_bytes
        self.vocab = vocab
        self.merges = merges
        self.special_tokens = special_tokens if special_tokens is not None else []
        # 构建 merge 优先级字典，用于快速查找
        self.merge_priority = {pair: i for i, pair in enumerate(merges)}

    @classmethod
    def from_files(
        cls, vocab_filepath: str, merges_filepath: str, special_tokens: list[str] = None
    ):
        with open(vocab_filepath, "r", encoding="utf-8") as f:
            vocab_raw = json.load(f)
        with open(merges_filepath, "r", encoding="utf-8") as f:
            merges_raw = json.load(f)

        # 转换 vocab: str key -> int key, list[int] value -> bytes value
        vocab = {int(k): bytes(v) for k, v in vocab_raw.items()}
        # 转换 merges: list[list[int]] -> tuple[bytes, bytes]
        merges = [(bytes(pair[0]), bytes(pair[1])) for pair in merges_raw]

        return cls(vocab, merges, special_tokens)

    def encode(self, text: str) -> list[int]:
        # 1. Pre-tokenization
        pre_tokenize_list = _pre_tokenizer_worker(text, self.special_tokens)

        # 2. 构建 token->id 的反向映射
        byte_to_id = {
            token_bytes: token_id for token_id, token_bytes in self.vocab.items()
        }

        ids = []
        for word in pre_tokenize_list:
            # 检查是否是特殊token
            if word in self.special_tokens:
                word_bytes = word.encode("utf-8")
                ids.append(byte_to_id[word_bytes])
                continue

            # 将每个字符转换为单字节的bytes对象
            word_bytes = [bytes([b]) for b in word.encode("utf-8")]
            # 对每个word单独进行BPE合并
            merged_tokens = self._merge_tokens(word_bytes)
            # Encode to ids
            ids.extend([byte_to_id[token] for token in merged_tokens])

        return ids

    def _merge_tokens(self, bytes_tokens: list[bytes]) -> list[bytes]:
        """应用BPE合并规则，按优先级顺序合并"""
        if len(bytes_tokens) <= 1:
            return bytes_tokens

        while True:
            # 找到优先级最高（索引最小）的可合并pair
            best_pair = None
            best_priority = float("inf")

            for i in range(len(bytes_tokens) - 1):
                pair = (bytes_tokens[i], bytes_tokens[i + 1])
                if pair in self.merge_priority:
                    priority = self.merge_priority[pair]
                    if priority < best_priority:
                        best_priority = priority
                        best_pair = pair

            # 如果没有可合并的pair，退出
            if best_pair is None:
                break

            # 合并所有该pair的出现
            new_token = best_pair[0] + best_pair[1]
            new_tokens = []
            i = 0
            while i < len(bytes_tokens):
                if (
                    i < len(bytes_tokens) - 1
                    and bytes_tokens[i] == best_pair[0]
                    and bytes_tokens[i + 1] == best_pair[1]
                ):
                    new_tokens.append(new_token)
                    i += 2
                else:
                    new_tokens.append(bytes_tokens[i])
                    i += 1
            bytes_tokens = new_tokens

        return bytes_tokens

    def encode_iterable(self, iterable: Iterable[str]) -> Iterator[int]:
        for text in iterable:
            ids = self.encode(text)
            for id_ in ids:
                yield id_

    def decode(self, ids: list[int]) -> str:
        # 先拼接所有bytes，再一次性解码，避免多字节Unicode字符被拆分
        all_bytes = b"".join(self.vocab[id_] for id_ in ids)
        return all_bytes.decode("utf-8", errors="replace")

## 3.Transformer Language Model Architecture
![transfomer架构](/img/in-post/2025-12-27/企业微信截图_17676102052191.png)

上图是经典的transfomer架构，输入一般是[batch_size, seq_len]的矩阵，其中seq_len是输入序列的长度，batch_size是batch的大小，比如一个batch有1000个句子，每个句子长度为100，那么batch_size就是1000，seq_len就是100。

然后是embedding层，这里是一个[seq_len, embedding_dim]的矩阵，embedding_dim是embedding的维度，也就是将token id映射到多少维度。

输入经过embedding层后，就会变成一个[batch_size, seq_len, embedding_dim]的矩阵，前面两个维度用来确定token的位置，最后一个维度一般是需要学习更新的参数。

随后，就可以经过transfomer块了。

transfomer块中包括了position encoding、multi-head self-attention、feed forward network以及layer normalization。

position encoding是用来表示token的位置信息的，比如第一个token的位置信息是0，第二个token的位置信息是1，以此类推。主流的方法有固定位置编码、相对位置编码和旋转编码。

multi-head self-attention是用来计算token之间的attention的，比如计算token1和token2之间的attention，token1和token3之间的attention，token2和token3之间的attention，token1和token4之间的attention，以此类推。

feed forward network是用来引入复杂度的，这样可以提高模型的表达能力。这里可以做的文章就是引入MOE架构，也就是水平分割FFN层，然后借助门控将每个token引导到不同的专家，这样可以降低推理时开销。

layer normalization是用来做normalization的，这样可以提高模型的收敛速度，目前主流一般是将post-norm改成pre-norm。

注意传统post-ln，是指将归一化层放在残差连接之后，而pre-ln是指将归一化层放在transfomer块之前。

经过num_layers个transfomer块后，就可以得到一个[batch_size, seq_len, embedding_dim]的矩阵，这里如果是采用pre-ln的话，那么在最后一个transfomer块输出的位置还需要接一个norm层。

最后，再经过一个线性层，就可以得到[batch_size, seq_len, vocab_size]的矩阵，这里的vocab_size是词表的大小，也就是有多少个token。

随后，就可以通过softmax层来计算每个token的概率了。

import torch


class Linear(torch.nn.Module):
    def __init__(
        self,
        in_features: int,
        out_features: int,
        device: torch.device | None = None,
        dtype: torch.dtype | None = None,
    ):
        super().__init__()
        # 用out_features x in_features的矩阵，因为这样内存连续性更好
        self.W: torch.nn.Parameter = torch.nn.Parameter(
            torch.empty((out_features, in_features), device=device, dtype=dtype)
        )
        # 用截断正态分布初始化权重
        torch.nn.init.trunc_normal_(self.W, std=0.02)

            raise ValueError(
                f"Input feature dimension {x.shape[-1]} does not match expected {self.W.shape[1]}"
            )
        return x @ self.W.T

## 3.1 有关Pre-Norm的讨论
传统的Transfomer架构采用的是post-norm，就是在Transfomer块的两个子层(attention层和position-wise层)后分别接一个layer norm，但是目前研究表明，将layer norm放在attention层前，即pre-norm，效果会更好。

一种直觉的解释是，post-norm的位置干扰了残差连接数据流的“纯净性”，从而打破了“原始”的尺度和分布。而pre-norm的位置在输入进残差流之前，这不会污染残差流的纯净。

另一点就是，采用pre-norm的话有利于训练的预热，因为刚开始就进行一个归一化，从而使得数据分布更加稳定，而post-norm则是在第一层输出后，再对输出进行归一化，这样会使得数据分布更加不稳定。

## 3.2 Root Mean Square Layer Normalization
我们先来看看传统layer-normalization的公式：
$$
\text{LayerNorm}(x) = \gamma \cdot \frac{x - \mu_x}{\sqrt{\sigma_x^2 + \epsilon}} + \beta
$$

其中：
- $$\mu_x = \frac{1}{D} \sum_{i=1}^{D} x_i$$ 是输入向量 $$x$$ 的均值
- $$\sigma_x^2 = \frac{1}{D} \sum_{i=1}^{D} (x_i - \mu_x)^2$$ 是输入向量 $$x$$ 的方差
- $$\epsilon$$ 是一个很小的常数，用于数值稳定性
- $$\gamma$$ 和 $$\beta$$ 是可学习的缩放和偏移参数

这里首先需要遍历一次计算均值，然后还得遍历一次计算方差并逐元素减均值，最后再计算归一化后的结果。这显然是一个非常耗时的操作。

当然，它的效果是没有问题的，经过了无数论文的实践。

但，有没有一种办法更好，更快呢？

答案是肯定的，那就是RMSNorm。

RMSNorm的公式如下：
$$
\text{RMSNorm}(x) = \gamma \cdot \frac{x}{\sqrt{\text{RMS}(x) + \epsilon}} + \beta
$$

其中：
- $$\text{RMS}(x) = \sqrt{\frac{1}{D} \sum_{i=1}^{D} x_i^2}$$ 是输入向量 $$x$$ 的均方根
- $$\epsilon$$ 是一个很小的常数，用于数值稳定性（通常会设置1e-5)
- $$\gamma$$ 和 $$\beta$$ 是可学习的缩放和偏移参数

可以看见，相比较传统ln，它只需要遍历一次来计算均方根，既没有逐元素操作，需要学习的参数还减少了一个。

毫无疑问，RMSNorm的计算开销绝对是比LayerNorm快很多的，但是快就一定好吗？

你别说，经过目前普遍实践，RMSNorm代替LayerNorm的训练效果并不差，甚至某些情况下还优于LayerNorm。

这简直是winwin。

import torch


class RMSNorm(torch.nn.Module):
    def __init__(
        self,
        d_model: int,
        eps: float = 1e-8,
        device: torch.device | None = None,
        dtype: torch.dtype | None = None,
    ):
        super().__init__()
        self.d_model = d_model
        self.eps = eps
        self.G = torch.nn.Parameter(torch.ones(d_model, device=device, dtype=dtype))
        torch.nn.init.trunc_normal_(self.G, std=0.02)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        in_dtype = x.dtype
        if x.shape[-1] != self.d_model:
            raise ValueError(
                f"Input feature dimension {x.shape[-1]} does not match expected {self.d_model}"
            )

        x = x.to(torch.float32)  # 使用更高精度计算均方根
        rms = torch.sqrt(torch.mean(x**2, dim=-1, keepdim=True) + self.eps)
        # 归一化并缩放
        x_normalized = x / rms
        result = x_normalized * self.G
        return result.to(in_dtype)

## 3.3 Position-Wise Feed-Forward Network
Transfomer中采用的FFN块是逐位置的，也就是说权重矩阵会分别和每个Token对应的embedding进行计算，而不是将所有token展开一并进行计算。

这里主要是因为attention层已经引入了位置关注的信息，在FFN这里没必要冗余地引入位置信息，这不仅开销巨大，还有可能影响attention的效果。

另外需要注意的是，虽然是逐位置计算，但是每次计算使用的都是同一个参数矩阵，也就是共享权重。

Transfomer的Position-Wise FFN会对D维先升维，再降维，也就是每个FFN包括两个线性层，第一个线性层将D维升维到4D，第二个线性层将4D维降维到D维，每次处理后都会使用激活函数来引入非线性(原始文章中使用的是ReLu)。

这么做是为了在高维丰富特征，并且引入非线性，从而提升模型的表达能力。

![激活函数对比图](/img/in-post/2025-12-27/企业微信截图_17676884962576.png)

大部分实践中激活函数都会采取ReLu，因为它计算高效、梯度稳定，虽然它在负数区域上会出现梯度消失的问题，但这也相对引入了一种稀疏激活的效果。

不过在LLM实践中，目前大部分现代模型如qwen和llama都采用了一种GLU激活函数，它具有门控机制，可以控制输入的激活程度，从而提升模型的表达能力。

$$
GLU(x) = f(x) \cdot \sigma(x)
$$

也就是让线性单元f(x)和一个激活函数(原论文是sigmoid)进行点乘，从而控制输入的激活程度。

而所谓的SwiGLU，就是用Swish激活函数来代替sigmoid，从而实现门控机制。

$$
SwiGLU(x) = f(x) \cdot Swish(x)

Swish(x) = x \cdot \sigma(x)=x \cdot \frac{1}{1+e^{-x}}
$$

(2 points)

import torch

class SwiGLU(torch.nn.Module):
    def __init__(
        self,
        d_model: int,
        d_ff: int | None = None,
        device: torch.device | None = None,
        dtype: torch.dtype | None = None,
    ):
        super().__init__()
        if d_ff and d_ff <= d_model:
            raise ValueError("d_ff should be greater than d_model")
        if d_ff is None:
            # 计算 8/3 * d_model 并向上取整到 64 的倍数
            base_d_ff = int(8 / 3 * d_model)
            d_ff = ((base_d_ff + 63) // 64) * 64  # 向上取整到 64 的倍数

        self.d_model = d_model
        self.d_ff = d_ff

        # SwiGLU 需要三个线性层：
        # w1: 用于第一个分支（带激活函数）
        # w2: 用于第二个分支（线性）
        # w3: 用于最终输出投影
        self.w1 = Linear(d_model, d_ff, device=device, dtype=dtype)
        self.w2 = Linear(d_ff, d_model, device=device, dtype=dtype)
        self.w3 = Linear(d_model, d_ff, device=device, dtype=dtype)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        SwiGLU 前向传播：
        SwiGLU(x) = Swish(x @ w1.T) ⊗ (x @ w2.T) @ w3.T

        其中：
        - Swish(z) = z * σ(z) （σ 是 sigmoid 函数）
        - ⊗ 表示逐元素乘法
        """
        # 第一个分支：应用 Swish 激活函数
        branch1 = self.w1(x)  # [..., d_model] @ [d_ff, d_model].T -> [..., d_ff]
        branch1_activated = torch.nn.functional.silu(branch1)  # Swish 激活

        # 第二个分支：线性变换（无激活）
        branch2 = self.w3(x)  # [..., d_model] @ [d_ff, d_model].T -> [..., d_ff]

        # 门控机制：逐元素相乘
        gated = branch1_activated * branch2  # [..., d_ff]

        # 最终投影回 d_model 维度
        output = self.w2(gated)  # [..., d_ff] @ [d_model, d_ff].T -> [..., d_model]

        return output

## 3.4 Relative Position Embeddings
Transfomer是无法感知位置的，所以我们需要引入位置编码，来让模型感知到位置信息。位置编码有两种，一种是相对位置编码，一种是绝对位置编码，目前主流是使用RoPE这样的相对位置编码。

绝对位置编码有两个实现：一种是直接添加一个同等维度的位置矩阵，一种是使用sin和cos函数来生成位置编码。前者实现简单但是没有外推能力，后者缺乏相对距离信息。

相对位置编码就是在推导式中引入类似i-j的影响，这样就能获取到不同距离之间位置的关系，目前主流的做法就是RoPE旋转编码，实际上我觉得就是基于绝对位置编码中正弦余弦实现版本的优化。

RoPE通过旋转矩阵将位置信息编码到向量空间中，其数学本质是利用旋转矩阵的群性质：对于任意两个位置i和j，旋转后的query和key的点积满足 (Rᵢq)·(Rⱼk) = q·(Rᵢ₋ⱼk)，从而在点积注意力中显式引入相对位置差i-j。

在工程实现上，RoPE采用了三重优化策略：
* 分块对角结构分解：将高维旋转矩阵分解为多个独立的2×2旋转块，每个块负责向量的一对相邻维度；
* 计算展平优化：将矩阵乘法转换为逐元素的代数运算，避免昂贵的矩阵操作，将时间复杂度从O(d²)降至O(d)；
* 预计算缓存：由于旋转角度仅依赖于位置索引，可以预先计算并存储所有位置的sin/cos值，在推理时直接查表使用。

最终的实现简化为：将输入向量的偶数维和奇数维分别视为复平面上的实部和虚部，对每个2D子空间独立应用旋转变换 [x₀, x₁] → [x₀cosθ - x₁sinθ, x₀sinθ + x₁cosθ]，从而在保持数学表达力的同时实现了显著的计算加速。

```python
import torch

class RoPE(torch.nn.Module):
    def __init__(self, theta: float, d_k: int, max_seq_len: int, device=None):
        super().__init__()
        self.theta = theta  # Θ value for the RoPE
        self.d_k = d_k
        self.max_seq_len = max_seq_len
        self._pre_cache_sin_cos(device)

    def _pre_cache_sin_cos(self, device=None):
        if self.d_k % 2 != 0:
            raise ValueError("d_k must be even")
        if device is None:
            device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

        position = torch.arange(self.max_seq_len, device=device)

        dim_indices = torch.arange(0, self.d_k, 2, device=device, dtype=torch.float32)

        freqs = 1 / self.theta ** (dim_indices / self.d_k)

        angles = torch.outer(position, freqs)

        self.register_buffer("sin", torch.sin(angles), persistent=False)
        self.register_buffer("cos", torch.cos(angles), persistent=False)

    def forward(
        self, x: torch.Tensor, token_positions: torch.Tensor = None
    ) -> torch.Tensor:
        origin_shape = x.shape
        *batch_dims, seq_len, dim = origin_shape

        if dim % 2 != 0:
            raise ValueError("Dimension must be even")
        if dim != self.d_k:
            raise ValueError(f"Last dim of x ({dim}) must equal d_k ({self.d_k})")

        x_flat = x.view(-1, dim)  # [B_total * seq_len, d_k]

        # 处理 token_positions
        if token_positions is None:
            base_pos = torch.arange(seq_len, device=x.device, dtype=torch.long)
            token_positions = base_pos.unsqueeze(0).expand(*batch_dims, seq_len)
        else:
            token_positions = token_positions.to(x.device)
            token_positions = token_positions.unsqueeze(0).expand(*batch_dims, seq_len)

        pos_flat = token_positions.reshape(-1)  # [B_total * seq_len]

        # 取出对应位置的 sin/cos，沿“序列位置”这一维索引
        sin_pos = self.sin[pos_flat]  # [B_total * seq_len, d_k/2]
        cos_pos = self.cos[pos_flat]  # [B_total * seq_len, d_k/2]

        # 拆偶数 / 奇数维
        x_flat_even = x_flat[:, 0::2]  # [B_total * seq_len, d_k/2]
        x_flat_odd = x_flat[:, 1::2]  # [B_total * seq_len, d_k/2]

        # 旋转
        rotated_even = x_flat_even * cos_pos - x_flat_odd * sin_pos
        rotated_odd = x_flat_even * sin_pos + x_flat_odd * cos_pos

        rotated_x = torch.zeros_like(x_flat)
        rotated_x[:, 0::2] = rotated_even
        rotated_x[:, 1::2] = rotated_odd

        return rotated_x.view(origin_shape)



```

```python
import torch
import math
from typing import Optional



class ScaledDotProductAttention(torch.nn.Module):
    def __init__(self, device=None):
        super().__init__()
        self._device = device

    def forward(
        self,
        Q: torch.Tensor,
        K: torch.Tensor,
        V: torch.Tensor,
        mask: Optional[torch.Tensor] = None,
    ) -> torch.Tensor:
        if Q.size(-1) != K.size(-1):
            raise ValueError("Incompatible shapes for Q, K, V tensors")

        d_k = Q.size(-1)
        scale = 1.0 / math.sqrt(float(d_k))

        # 计算注意力分数: (..., Lq, Lk)
        attn_scores = torch.matmul(Q, K.transpose(-2, -1)) * scale

        if mask is not None:
            # 支持两种 mask 格式：
            # 1. boolean mask: True 表示保留，False 表示屏蔽
            # 2. 数值型 attention bias: 直接加到 attention scores 上
            if mask.dtype == torch.bool:
                attn_scores = attn_scores.masked_fill(
                    ~mask, torch.finfo(attn_scores.dtype).min
                )
            else:
                attn_scores = attn_scores + mask

        attn_weights = torch.softmax(attn_scores.float(), dim=-1).to(attn_scores.dtype)
        output = torch.matmul(attn_weights, V)
        return output

```python
import torch
import math
from typing import Optional



class MultiHeadAttention(torch.nn.Module):
    def __init__(
        self,
        d_model: int,
        num_heads: int,
        max_seq_len: int = None,
        theta: float = None,
        token_positions: torch.Tensor = None,
        device=None,
    ):
        super().__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        if d_model % num_heads != 0:
            raise ValueError("d_model must be divisible by num_heads")
        self.d_k = d_model // num_heads

        self.q_proj = Linear(d_model, d_model, device=device)
        self.k_proj = Linear(d_model, d_model, device=device)
        self.v_proj = Linear(d_model, d_model, device=device)
        self.o_proj = Linear(d_model, d_model, device=device)
        self.attention = ScaledDotProductAttention(device=device)
        self.rope = None  # 默认初始化为 None
        if max_seq_len and theta:
            self.rope = RoPE(
                theta=theta, d_k=self.d_k, max_seq_len=max_seq_len, device=device
            )

        self.device = device

    def forward(
        self,
        x: torch.Tensor,
        mask: Optional[torch.Tensor] = None,
        is_causal: bool = True,
        token_positions: Optional[torch.Tensor] = None,
    ) -> torch.Tensor:
        B = x.size(0)
        n = x.size(-2)
        m = x.size(-2)

        Q = self.q_proj(x).view(B, n, self.num_heads, self.d_k).transpose(1, 2)
        K = self.k_proj(x).view(B, m, self.num_heads, self.d_k).transpose(1, 2)
        V = self.v_proj(x).view(B, m, self.num_heads, self.d_k).transpose(1, 2)

        if self.rope is not None:
            Q = self.rope(Q, token_positions)
            K = self.rope(K, token_positions)

        attn_bias = None
        if is_causal:
            causal_mask = torch.triu(
                torch.full(
                    (n, m), torch.finfo(x.dtype).min, device=x.device, dtype=x.dtype
                ),
                diagonal=1,
            )
            attn_bias = causal_mask

        bias = None
        if mask is not None:
            if mask.dtype == torch.bool:
                bias = torch.zeros(
                    B, self.num_heads, n, m, dtype=x.dtype, device=x.device
                )
                bias = bias.masked_fill(~mask, torch.finfo(x.dtype).min)
            else:
                bias = mask
        if bias is not None and attn_bias is not None:
            attn_bias = torch.max(bias, attn_bias)
        elif bias is not None:
            attn_bias = bias

        output = self.attention(Q, K, V, attn_bias)
        output = output.transpose(1, 2).contiguous().view(B, n, self.d_model)
        output = self.o_proj(output)
        return output


```

import torch
import math
from typing import Optional

class TransformerBlock(torch.nn.Module):
    def __init__(
        self,
        d_model: int,
        num_heads: int,
        dff: int,
        max_seq_len: int,
        theta: float,
        weights: dict[str, torch.Tensor] = None,
        device: torch.device | None = None,
        dtype: torch.dtype = torch.float32,
        eps: float = 1e-5,
    ):
        super().__init__()

        self.mha = MultiHeadAttention(
            d_model, num_heads, max_seq_len, theta, device, dtype
        )
        self.rms1 = RMSNorm(d_model, eps=eps, device=device, dtype=dtype)
        self.rms2 = RMSNorm(d_model, eps=eps, device=device, dtype=dtype)
        self.ffn = SwiGLU(d_model, dff, device=device, dtype=dtype)

        if weights:
            self._load_weights(weights)

    def _load_weights(self, weights: dict[str, torch.Tensor]):
        self.mha.load_state_dict(
            {
                "q_proj.W": weights["attn.q_proj.weight"],
                "k_proj.W": weights["attn.k_proj.weight"],
                "v_proj.W": weights["attn.v_proj.weight"],
                "o_proj.W": weights["attn.output_proj.weight"],
            }
        )
        self.rms1.load_state_dict({"G": weights["ln1.weight"]})
        self.rms2.load_state_dict({"G": weights["ln2.weight"]})
        self.ffn.load_state_dict(
            {
                "w1.W": weights["ffn.w1.weight"],
                "w2.W": weights["ffn.w2.weight"],
                "w3.W": weights["ffn.w3.weight"],
            }
        )

    def forward(
        self,
        x: torch.Tensor,
        mask: Optional[torch.Tensor] = None,
        is_causal: bool = True,
        token_positions: Optional[torch.Tensor] = None,
    ) -> torch.Tensor:
        # Pre-norm + 残差连接
        x = x + self.mha(self.rms1(x), mask, is_causal, token_positions)
        x = x + self.ffn(self.rms2(x))
        return x

import torch
import math
from typing import Optional

class TransformerLM(torch.nn.Module):
    def __init__(
        self,
        vocab_size: int,
        context_length: int,
        num_layers: int,
        d_model: int,
        rope_theta: float = 10000.0,
        num_heads: int = 8,
        dff: int = None,
        dtype: torch.dtype = torch.float32,
        eps: float = 1e-5,
    ):

        self.vocab_size = vocab_size
        self.context_length = context_length
        self.num_layers = num_layers
        self.d_model = d_model
        self.num_heads = num_heads
        self.dff = dff
        self.rope_theta = rope_theta
        self.eps = eps

        self.embedding = Embedding(vocab_size, d_model, dtype=dtype)
        self.transformer_blocks = torch.nn.ModuleList(
            [
                TransformerBlock(
                    d_model,
                    num_heads,
                    dff,
                    max_seq_len=context_length,
                    theta=rope_theta,
                    weights=None,
                    device=None,
                    dtype=dtype,
                    eps=eps,
                )
                for _ in range(num_layers)
            ]
        )
        self.ln_final = RMSNorm(d_model, eps=eps, dtype=dtype)
        self.lm_head = Linear(d_model, vocab_size, device=None, dtype=dtype)

    def _load_weights(self, weights: dict[str, torch.Tensor]):
        """加载预训练权重"""
        # 加载词嵌入
        self.embedding.load_state_dict(
            {"embedding_matrix": weights["token_embeddings.weight"]}
        )

        # 加载每层 transformer block 的权重
        for i, block in enumerate(self.transformer_blocks):
            layer_weights = {
                "attn.q_proj.weight": weights[f"layers.{i}.attn.q_proj.weight"],
                "attn.k_proj.weight": weights[f"layers.{i}.attn.k_proj.weight"],
                "attn.v_proj.weight": weights[f"layers.{i}.attn.v_proj.weight"],
                "attn.output_proj.weight": weights[
                    f"layers.{i}.attn.output_proj.weight"
                ],
                "ln1.weight": weights[f"layers.{i}.ln1.weight"],
                "ln2.weight": weights[f"layers.{i}.ln2.weight"],
                "ffn.w1.weight": weights[f"layers.{i}.ffn.w1.weight"],
                "ffn.w2.weight": weights[f"layers.{i}.ffn.w2.weight"],
                "ffn.w3.weight": weights[f"layers.{i}.ffn.w3.weight"],
            }
            block._load_weights(layer_weights)

        # 加载最终的 RMSNorm
        self.ln_final.load_state_dict({"G": weights["ln_final.weight"]})

        # 加载语言模型头
        self.lm_head.load_state_dict({"W": weights["lm_head.weight"]})

    def forward(self, in_indices: torch.Tensor) -> torch.Tensor:
        # 词嵌入
        x = self.embedding(in_indices)

        # 通过所有 transformer blocks
        for block in self.transformer_blocks:
            x = block(x)

        # 最终的 RMSNorm
        x = self.ln_final(x)

        # 投影到词表大小，返回 unnormalized logits
        return self.lm_head(x)

## 3.9 Cross-entropy loss
下一步就是实现损失函数，Transfomer一般使用交叉熵来计算概率差异损失。

简单来说，就是计算-log(p(y|x))，其中p(y|x)是模型预测y的概率，x是输入，y是输出。

然后p(y|x)也很好算，看一下真实token对应的预测概率，然后除上总的概率和就行。

真实token的位置，实际上就是原始输入的sequence维度向上平移一下，也就是原本sequence[i]索引位置对应的token id，变成了sequence[i+1]的token id，也就是下一个词。

所以，loss函数可以这样实现：

>
> 用torch实现Cross-entropy

import torch

class CrossEntropyLoss(torch.nn.Module):
    def __init__(self, reduction: str = "mean"):
        super().__init__()
        self.reduction = reduction

    def forward(self, inputs: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
        max_logits = torch.max(inputs, dim=-1, keepdim=True)[0]
        stable_logits = inputs - max_logits
        exp_logits = torch.exp(stable_logits)
        sum_exp_logits = torch.sum(exp_logits, dim=-1, keepdim=True)
        log_sum_exp_logits = torch.log(sum_exp_logits)

        losses = (
            log_sum_exp_logits.squeeze(-1)
            - stable_logits[
                torch.arange(targets.shape[0], device=targets.device), targets
            ]
        )

        if self.reduction == "mean":
            return losses.mean()
        elif self.reduction == "sum":
            return losses.sum()
        else:  # "none"
            return losses

## 3.10 AdamW optimizer
优化器是用来更新模型参数的，它会根据学习率和梯度来更新参数，最简单的优化器是SGD，它会直接使用学习率和梯度来更新参数，但问题就在于需要精心调试合适的学习率。

另一个优化器就是带冲量的SGD，它的底层逻辑就是去存储一个梯度的变化累计，这样就能保证梯度更新会带有一个“惯性”，从而防止梯度更新不稳定。

基于这个思想，又衍生出了Adam优化器。我们可以把冲量SGD看作是一阶状态累积，Adam是在这个基础上，既保存了一阶状态累积，又保存了二阶状态累积。

当然，这付出的代价就是每个参数都需要维护两个状态，所以它的计算成本会更高。

AdamW是Adam的变种，它发现在传统Adam中，2正则项被直接加到了梯度里，而这个“带正则的梯度”又参与了自适应学习率的计算，导致约束效果被严重削弱，AdamW 的核心改进就是将权重衰减从梯度计算中解耦出来，使其不再受自适应学习率的影响。

下一步就是实现AdamW optimizer，这是目前LLM最常用的optimizer。


> Problem (transformer_lm): Implementing the AdamW optimizer (3 points)
>
> 用torch实现AdamW optimizer
<details>
<summary style="cursor: pointer; display: inline-block; padding: 8px 16px; background: #007bff; color: white; border-radius: 4px; font-size: 14px; margin: 10px 0;">📄 点击展开AdamW optimizer完整代码</summary>


<div markdown="1">

```python
import torch

class AdamW(torch.optim.Optimizer):
    def __init__(
        self,
        params,
        betas: tuple[float, float],
        eps: float,
        lr: float,
        weight_decay: float,
    ):
        defaults = dict(
            betas=betas,
            eps=eps,
            weight_decay=weight_decay,
            lr=lr,
        )
        super().__init__(params, defaults)

    @torch.no_grad()
    def step(self, closure=None):
        loss = None
        if closure is not None:
            loss = closure()
        for group in self.param_groups:
            lr = group["lr"]
            beta1, beta2 = group["betas"]
            eps = group["eps"]
            weight_decay = group["weight_decay"]

            for p in group["params"]:
                if p.grad is None:
                    continue
                grad = p.grad

                state = self.state[p]
                if len(state) == 0:
                    state["step"] = 0
                    state["m"] = torch.zeros_like(p)
                    state["v"] = torch.zeros_like(p)

                m, v = state["m"], state["v"]
                state["step"] += 1
                t = state["step"]

                # 更新一阶、二阶矩估计
                m.mul_(beta1).add_(grad, alpha=1 - beta1)
                v.mul_(beta2).addcmul_(grad, grad, value=1 - beta2)

                # 偏差校正
                m_hat = m / (1 - beta1**t)
                v_hat = v / (1 - beta2**t)

                # 计算自适应更新量
                update = m_hat / (v_hat.sqrt() + eps)
                # 应用 Adam 更新
                p.add_(update, alpha=-lr)
                # 应用解耦的权重衰减
                p.mul_(1 - lr * weight_decay)

        return loss

```

## 3.11 LR Scheduler
在训练过程中，能够使损失值快速下降的学习率往往是动态变化的。

我们通常会在训练初期使用较大的学习率，随着训练的进行，逐渐降低学习率，以获得更好的训练效果。为了实现这一目标，我们通常会使用学习率调度器（LR Scheduler）。

目前普遍使用的学习率调度器是Cosine Scheduler，它会有Tw、Tc、min_lr、max_lr四个参数，分别表示热身周期、余弦退火周期、最小学习率、最大学习率。

在热身周期内，学习率会从min_lr逐渐增加到max_lr。

在余弦退火周期内，学习率会从max_lr逐渐减少到min_lr。

超过Tc后，学习率会保持为min_lr。

> Problem (transformer_lm): Implementing the LRScheduler (3 points)
>
> 用torch实现LRScheduler
<details>
<summary style="cursor: pointer; display: inline-block; padding: 8px 16px; background: #007bff; color: white; border-radius: 4px; font-size: 14px; margin: 10px 0;">📄 点击展开LRScheduler完整代码</summary>


<div markdown="1">

```python
import torch

def LRScheduler(
    it: int,
    max_learning_rate: float,
    min_learning_rate: float,
    warmup_iters: int,
    cosine_cycle_iters: int,
):
    if it < warmup_iters:
        lr = max_learning_rate * (it / warmup_iters)
    elif warmup_iters <= it < cosine_cycle_iters:
        lr = min_learning_rate + 0.5 * (max_learning_rate - min_learning_rate) * (
            1
            + math.cos(
                math.pi * (it - warmup_iters) / (cosine_cycle_iters - warmup_iters)
            )
        )
    else:
        lr = min_learning_rate
    return lr

## 3.12 Gradient clipping
在训练过程中，我们会遇到一些梯度很大的样本，这会导致训练不稳定，常采取的一种解决方法就是梯度裁剪。

它的思想就是在每次反向传播后，执行优化器之前，对梯度进行一个范数限制。

这里实现时需要注意，我们计算的范数是全局的，而不是遍历每个参数计算单独的范数。

> Problem (transformer_lm): Implementing the Gradient Clipping (3 points)
>
> 用torch实现Gradient Clipping

<summary style="cursor: pointer; display: inline-block; padding: 8px 16px; background: #007bff; color: white; border-radius: 4px; font-size: 14px; margin: 10px 0;">📄 点击展开Gradient Clipping完整代码</summary>

```python
import torch

def gradient_clipping(parameters: Iterable[torch.nn.Parameter], max_norm: float):
    # 计算全局梯度范数
    total_norm = torch.sqrt(
        sum(p.grad.data.norm(2) ** 2 for p in parameters if p.grad is not None)
    )
    if total_norm > max_norm:
        # 计算全局裁剪系数
        clip_coef = max_norm / (total_norm + 1e-6)
        # 统一缩放所有梯度
        for p in parameters:
            if p.grad is not None:
                p.grad.data.mul_(clip_coef)

import numpy.typing as npt
import numpy as np


def data_loader(
    dataset: npt.NDArray, batch_size: int, context_length: int, device: str
) -> tuple[torch.Tensor, torch.Tensor]:
    start_index = torch.randint(len(dataset) - context_length, (batch_size,))
    inputs = torch.stack(
        [
            torch.from_numpy(dataset[i : i + context_length].astype(np.int64))
            for i in start_index
        ]
    ).to(device)

    targets = torch.stack(
        [
            torch.from_numpy(dataset[i + 1 : i + 1 + context_length].astype(np.int64))
            for i in start_index
        ]
    ).to(device)

    return inputs, targets

import os

def save_checkpoint(
    model: torch.nn.Module,
    optimizer: torch.optim.Optimizer,
    iteration: int,
    out: str | os.PathLike | typing.BinaryIO | typing.IO[bytes],
):
    checkpoint = {
        "model_state_dict": model.state_dict(),
        "optimizer_state_dict": optimizer.state_dict(),

def load_checkpoint(
    src: str | os.PathLike | typing.BinaryIO | typing.IO[bytes],
    model: torch.nn.Module,
    optimizer: torch.optim.Optimizer,
):
    checkpoint = torch.load(src, map_location="cpu")
    model.load_state_dict(checkpoint["model_state_dict"])
    optimizer.load_state_dict(checkpoint["optimizer_state_dict"])
    iteration = checkpoint["iteration"]
    return iteration

def prepare_tokenized_data(
    tokenizer: Tokenizer,
    text_path: Path,
    output_path: Path,
    chunk_size: int = 10 * 1024 * 1024,  # 10MB per chunk
) -> None:
    """流式tokenize大文件，避免一次性加载到内存"""
    print(f"Tokenizing {text_path} (streaming)...")
    file_size = text_path.stat().st_size

    all_tokens = []
    processed = 0
    remainder = ""

    with open(text_path, "r", encoding="utf-8") as f:
        while True:
            chunk = f.read(chunk_size)
            if not chunk:
                break

            # 处理上一块的残余 + 当前块
            text = remainder + chunk

            # 找到最后一个完整句子（以换行符或空格结尾）
            # 避免在单词中间切断
            last_break = max(text.rfind("\n"), text.rfind(" "), text.rfind("."))
            if last_break > 0 and len(chunk) == chunk_size:
                remainder = text[last_break + 1 :]
                text = text[: last_break + 1]
            else:
                remainder = ""

            tokens = tokenizer.encode(text)
            all_tokens.extend(tokens)

            processed += len(chunk)
            print(
                f"  Progress: {processed / file_size * 100:.1f}% ({len(all_tokens):,} tokens)",
                end="\r",
            )

    # 处理最后的残余
    if remainder:
        tokens = tokenizer.encode(remainder)
        all_tokens.extend(tokens)

    print()  # 换行
    tokens_array = np.array(all_tokens, dtype=np.uint16)
    np.save(output_path, tokens_array)
    print(f"Saved {len(all_tokens):,} tokens to {output_path}")


def load_dataset(path: Path) -> np.ndarray:
    return np.load(path, mmap_mode="r")


@torch.no_grad()
def estimate_loss(model, train_data, val_data, config) -> dict:
    model.eval()
    losses = {}
    loss_fn = kt.CrossEntropyLoss(reduction="mean")

    for split, data in [("train", train_data), ("val", val_data)]:
        total_loss = 0.0
        for _ in range(config.eval_iters):
            inputs, targets = kt.data_loader(
                data, config.batch_size, config.context_length, config.device
            )
            logits = model(inputs)
            B, T, V = logits.shape
            loss = loss_fn(logits.view(B * T, V), targets.view(B * T))
            total_loss += loss.item()
        losses[split] = total_loss / config.eval_iters

    model.train()
    return losses


def train(config: TrainConfig = None):
    if config is None:
        config = TrainConfig()

    config.checkpoint_dir.mkdir(parents=True, exist_ok=True)
    TOKENIZER_OUTPUT_DIR.mkdir(parents=True, exist_ok=True)

    # 1. Tokenizer
    print("\n[1/7] Preparing Tokenizer")
    train_tokenizer_if_needed(config)

    # 2. 加载 Tokenizer
    print("\n[2/7] Loading Tokenizer")
    tokenizer = Tokenizer.from_files(
        vocab_filepath=str(config.vocab_path),
        merges_filepath=str(config.merges_path),
        special_tokens=config.bpe_special_tokens,
    )
    config.vocab_size = len(tokenizer.vocab)
    print(f"Vocab size: {config.vocab_size}")

    # 3. 数据预处理
    print("\n[3/7] Preparing Data")
    if not config.train_data_path.exists():
        prepare_tokenized_data(
            tokenizer, config.train_text_path, config.train_data_path
        )
    if not config.val_data_path.exists():
        prepare_tokenized_data(tokenizer, config.val_text_path, config.val_data_path)

    # 4. 加载数据
    print("\n[4/7] Loading Data")
    train_data = load_dataset(config.train_data_path)
    val_data = load_dataset(config.val_data_path)
    print(f"Train: {len(train_data):,} tokens, Val: {len(val_data):,} tokens")

    # 5. 初始化模型
    print("\n[5/7] Initializing Model")
    model = kt.TransformerLM(
        vocab_size=config.vocab_size,
        context_length=config.context_length,
        num_layers=config.num_layers,
        d_model=config.d_model,
        num_heads=config.num_heads,
        dff=config.d_ff,
        rope_theta=config.rope_theta,
        dtype=config.dtype,
    ).to(config.device)

    num_params = sum(p.numel() for p in model.parameters())
    print(f"Parameters: {num_params:,} ({num_params/1e6:.2f}M)")

    # 6. 优化器
    print("\n[6/7] Initializing Optimizer")
    optimizer = kt.AdamW(
        params=model.parameters(),
        lr=config.max_lr,
        betas=(config.beta1, config.beta2),
        eps=config.eps,
        weight_decay=config.weight_decay,
    )

    start_iter = 0
    if config.resume_from and os.path.exists(config.resume_from):
        start_iter = kt.load_checkpoint(config.resume_from, model, optimizer)
        print(f"Resumed from iter {start_iter}")

    loss_fn = kt.CrossEntropyLoss(reduction="mean")

    # 7. 训练
    print(
        f"\n[7/7] Training (iters={config.max_iters}, batch={config.batch_size}, ctx={config.context_length})"
    )
    model.train()

    for it in range(start_iter, config.max_iters):
        t0 = time.time()

        # 学习率调度
        lr = kt.LRScheduler(
            it=it,
            max_learning_rate=config.max_lr,
            min_learning_rate=config.min_lr,
            warmup_iters=config.warmup_iters,
            cosine_cycle_iters=config.cosine_cycle_iters,
        )
        for param_group in optimizer.param_groups:
            param_group["lr"] = lr

        inputs, targets = kt.data_loader(
            train_data, config.batch_size, config.context_length, config.device
        )

        B, T, V = logits.shape

        optimizer.zero_grad()
        loss.backward()
        kt.gradient_clipping(model.parameters(), config.grad_clip)
        optimizer.step()

        dt = time.time() - t0
        tokens_per_sec = config.batch_size * config.context_length / dt

        if it % 10 == 0:

                f"iter {it:5d} | loss {loss.item():.4f} | lr {lr:.2e} | {dt*1000:.1f}ms | {tokens_per_sec:.0f} tok/s"
            )

        if it > 0 and it % config.eval_interval == 0:

            print(
                f"[Eval] iter {it}: train={losses['train']:.4f}, val={losses['val']:.4f}"
            )

        if it > 0 and it % config.save_interval == 0:

            kt.save_checkpoint(model, optimizer, it, str(ckpt_path))
            print(f"[Saved] {ckpt_path}")

@torch.no_grad()
def generate(
    model,
    tokenizer,
    prompt: str,
    max_new_tokens: int = 100,
    temperature: float = 1.0,
    top_k: int = 50,
    device: str = "cuda",
) -> str:
    model.eval()
    input_ids = torch.tensor(
        tokenizer.encode(prompt), dtype=torch.long, device=device
    ).unsqueeze(0)

    for _ in range(max_new_tokens):
        input_ids_cond = input_ids[:, -model.context_length :]
        logits = model(input_ids_cond)[:, -1, :] / temperature

        if top_k > 0:
            v, _ = torch.topk(logits, min(top_k, logits.size(-1)))
            logits[logits < v[:, [-1]]] = float("-inf")

        probs = torch.softmax(logits, dim=-1)
        next_token = torch.multinomial(probs, num_samples=1)
        input_ids = torch.cat([input_ids, next_token], dim=1)

        if next_token.item() == tokenizer.vocab.get(b"\<|endoftext|\>", -1):
            break

    return tokenizer.decode(input_ids[0].tolist())
