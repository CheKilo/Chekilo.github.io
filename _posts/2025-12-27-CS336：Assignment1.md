### 2.1 Unicode Standard

Unicode 标准定义了世界上所有字符的编码，它将每个字符都映射到一个唯一的**码点（Code Point）**，即一个整数。

它可以看作是一个巨大的字典，给世界上每个字符都发了一张身份证 ID。比如：
- 汉字 `中` 的 ID 是 20013
- 英文字母 `a` 的 ID 是 97

这个数字只定义了唯一性，并没有定义在计算机中的存储方式，这就引申出了另一个话题——**编码**。

> Problem (unicode1): Understanding Unicode (1 point)
>
> (a) `chr(0)` 返回什么 Unicode 字符？
>
> 答：空字符（NUL character）
>
> (b) `__repr__()` 和 `print()` 的显示有什么不同？
>
> 答：`__repr__()` 返回转义表示形式（如 `'\\x00'`），而 `print()` 打印实际显示效果（通常不可见）。
>
> (c) 当字符串中包含 `chr(0)` 时会发生什么？
>
> ```python
> >>> chr(0)
> >>> print(chr(0))
> >>> "this is a test" + chr(0) + "string"
> >>> print("this is a test" + chr(0) + "string")
> ```
>
> 答：`chr(0)` 是空字符，在字符串中不会显示任何内容，但它确实存在于字符串中。

### 2.2 Encoding

目前针对 Unicode 标准，主要有三种编码方式：

| 编码方式 | 类型 | 说明 |
|---------|------|------|
| UTF-8 | 变长编码 | 码点 ≤127 使用 1 字节，>127 使用 2-4 字节 |
| UTF-16 | 定长编码 | 码点 ≤65535 使用 2 字节，>65535 使用 4 字节 |
| UTF-32 | 定长编码 | 不管码点是多少都使用 4 字节 |

注意：UTF-16 和 UTF-32 都有字节序问题（大端序/小端序）。

UTF-8 没有字节序问题，因为它的字节本身就包含了字节序信息：

```
0xxxxxxx                              (1 字节)
110xxxxx 10xxxxxx                     (2 字节)
1110xxxx 10xxxxxx 10xxxxxx            (3 字节)
11110xxx 10xxxxxx 10xxxxxx 10xxxxxx   (4 字节)
```

字节头部的 `0`、`110`、`1110`、`11110` 标识了字节数，自然不存在字节序问题。

> Problem (unicode2): Unicode Encodings (3 points)
>
> (a) 为什么更倾向于使用 UTF-8 编码来训练 tokenizer？
>
> 答：1. 空间效率更高，对于常见的 ASCII 字符只需 1 字节；2. 无字节序问题，而 UTF-16 和 UTF-32 都需要处理大小端问题
>
> (b) 下面的 UTF-8 解码函数为什么是错误的？
>
> ```python
> def decode_utf8_bytes_to_str_wrong(bytestring: bytes):
>     return "".join([bytes([b]).decode("utf-8") for b in bytestring])
>
> >>> decode_utf8_bytes_to_str_wrong("hello".encode("utf-8"))
> 'hello'
> ```
>
> 答：对于编码后只占 1 个字节的字符，这样解码是正确的。但对于编码后占多个字节的字符（如中文），它会尝试将每个字节单独解码，从而导致 `UnicodeDecodeError`。
>
> (c) 给出一个不能解码为任何 Unicode 字符的两字节序列。
>
> ```python
> print(b"\xc0\x80".decode("utf-8"))  # 会抛出 UnicodeDecodeError
> ```
>
> 这也解释了为什么 UTF-8 不存在字节序问题——它的字节本身就包含了字节序信息，一旦没有按照预期解码，就会导致错误，而不是生成错误的解码结果。


### 2.3 Subword Tokenization
使用byte-level的tokenizer，虽然能缓解词汇表OOV的问题，但把文本按字节级切分会导致输入序列过长（但是embedding的参数量会小）

这个问题很好理解，比如Apple，如果这个按照词意分割，那么它的token就是`apple`，但如果按照字节，那么它的token就是`a`、`p`、`p`、`l`、`e`，这样输入序列就变成了5个token，长度是原来的5倍。

attention层的复杂度是n方，n过长就会导致计算爆炸。

而subword tokenizer就是介于两者之间的，它将文本按字节切分，然后对切分后的字节序列进行subword切分，这样就能解决输入序列过长的问题，同时也能缓解OOV问题。

基于BPE实现的subword tokenizer，就叫做BPE分词器，这也是本次assigment要实现的一个内容。

### 2.4 BPE Tokenizer Training

**Vocabulary initialzation**：本assigment训练的是byte-level的BPE tokenizer，所以初始的词汇表大小是256，这对应了一个字节所能表示的范围。

**Pre-Tokenization**：有了初始词汇表，理论上是可以开始统计不同相邻字节的频率，然后对高频字节对进行合并，但是这里存在一个问题，那就是直接对语料库进行遍历的计算开销是非常大的（每次合并一对字节（比如 b'o'+ b'g'→ b'og'），你都需要重新扫描整个语料库，看看这个新字节对出现在哪里。），而且还会遇到一些特殊的问题。

例如：dog!和dog?，这里仅仅存在标点符号的不同，但是如果直接进行统计，就会产生两种截然不同的token IDs。

为了解决这些问题，可以使用预分词。

我们先对文本进行一次粗粒度的切分（预分词），然后利用这些预分词的出现频率，来快速统计“字符对”或“字节对”的出现次数，从而避免每次合并时都去扫描整个语料库，大大提升效率。

而且统计频率时，可以直接统计预分词的出现频率，而不需要统计每个字符的出现频率，因为预分词的出现频率，就代表了每个字符的出现频率。

例如“text”这个单词，统计t e出现的频率时，可以直接把text的数量加到t和e的频率上，而不需要单独统计t和e的出现频率。

原始的BPE实现是使用空格作为预分词，这太简单了，在本asigment中，会使用基于正则表达式的方法：

> ```python
> import regex as re
> PAT = r"""'(?:[sdmt]|ll|ve|re)| ?\p{L}+| ?\p{N}+| ?[^\s\p{L}\p{N}]+|\s+(?!\S)|\s+"""
> re.findall(PAT, "some text that i'll pre-tokenize")
> ```

| 正则 | 用途  |
|---------|------|
| (?:[sdmt]|ll|ve|re) | 匹配ll、ve、re，都是英语常见的简化写法 | 
| ?\p{L}+ | 匹配一个可选空格 + 一个或多个字母（支持多语言，如英文、中文） |
| ?\p{N}+ | 匹配一个可选空格 + 一个或多个数字（如 123, 456） | 
| ?[^\s\p{L}\p{N}]+| 匹配一个可选空格 + 一个或多个符号（如标点 !, ..., @#$） |
| \s+(?!\S) | 匹配末尾的空白（如行尾空格），用于保留格式 |
| \s+ | 匹配其他空白字符（如普通空格、换行），但通常会被前一项抢先匹配 |

这里需要注意，实际操作时要避免使用re.findall()，因为它会一次性返回所有匹配结果，语料库很大的话会占用大量内存，应该使用re.finditer()，每次返回一个匹配结果。

**Compute BPE merges**：有了预分词后，就可以正式利用BPE来做合并了，这里为了方便，不考虑跨词合并，并且相同词频的前提下，会采用字典序较大的对进行合并。

**Special tokens**：一些字符串（例如 <|endoftext|>）被用来编码元数据，我们希望将它们视为‘特殊 token’，永远不被拆分。

在生成文本时（比如聊天机器人回复），模型会不断预测下一个 token。当它输出 <|endoftext|>这个 token 时，就知道应该停止了。所以这个特殊token必须加入词汇表分配一个固定的ID，如果它也被拆分(["<|", "end", "of", "text", "|>", "]"])，那么模型就不知道什么时候该停止了。

```python
import os
import multiprocessing
from functools import partial
import regex as re
from cs336_basics.pretokenization_example import find_chunk_boundaries

PAT = r"""'(?:[sdmt]|ll|ve|re)| ?\p{L}+| ?\p{N}+| ?[^\s\p{L}\p{N}]+|\s+(?!\S)|\s+"""


def run_train_bpe(
    input_path: str | os.PathLike,
    vocab_size: int,
    special_tokens: list[str],
    **kwargs,
) -> tuple[dict[int, bytes], list[tuple[bytes, bytes]]]:
    """tuple[dict[int, bytes], list[tuple[bytes, bytes]]]:
    dict是vocab词汇表, list是merges列表"""

    # 预分词
    pre_tokenize_list = pre_tokenize(input_path, special_tokens)

    # 将特殊token转换为bytes集合，用于跳过
    special_token_set = set(special_tokens)

    # 将预分词列表转换为字节列表
    # 这里每个元素应该是 bytes 类型，而不是单个整数
    word_freq = {}
    for word in pre_tokenize_list:
        # 跳过特殊token，它们不参与BPE合并
        if word in special_token_set:
            continue
        # 将每个字符转换为单字节的 bytes 对象
        word_bytes = tuple(bytes([b]) for b in word.encode("utf-8"))
        word_freq[word_bytes] = word_freq.get(word_bytes, 0) + 1

    # 初始化词汇表(256个字节范围加上特殊token)
    vocab = {i: bytes([i]) for i in range(256)}
    for token in special_tokens:
        token_bytes = token.encode("utf-8")
        if token_bytes not in vocab.values():
            vocab[len(vocab)] = token_bytes

    merges = []

    # 初始化 pair_freq，只统计一次
    pair_freq = count_pair_frequencies(word_freq)

    # 下面是BPE算法的核心逻辑，loop的退出条件是vocab_size
    while len(vocab) < vocab_size:
        if not pair_freq:
            break

        # 1.根据频次找到最佳对进行BPE合并，如果频率相同，合并字典序更大的对
        best_pair = find_best_pair(pair_freq)
        if best_pair is None:
            break

        new_token = best_pair[0] + best_pair[1]
        vocab[len(vocab)] = new_token
        merges.append(best_pair)

        # 2.更新word_freq 和 pair_freq（增量更新）
        update_word_freq_and_pair_freq(word_freq, pair_freq, best_pair)

    return vocab, merges


def update_word_freq_and_pair_freq(
    word_freq: dict[tuple[bytes, ...], int],
    pair_freq: dict[tuple[bytes, bytes], int],
    best_pair: tuple[bytes, bytes],
) -> None:
    """更新word_freq和pair_freq（增量更新）"""
    new_token = best_pair[0] + best_pair[1]

    # 找出所有包含 best_pair 的 word
    words_to_update = []
    for word, freq in word_freq.items():
        for i in range(len(word) - 1):
            if word[i] == best_pair[0] and word[i + 1] == best_pair[1]:
                words_to_update.append((word, freq))
                break

    # 删除被合并的pair
    if best_pair in pair_freq:
        del pair_freq[best_pair]

    for word, freq in words_to_update:
        # 从 word_freq 中删除旧的 word
        del word_freq[word]

        # 先减去旧word的pair频次
        for i in range(len(word) - 1):
            pair = (word[i], word[i + 1])
            if pair in pair_freq:
                pair_freq[pair] -= freq
                if pair_freq[pair] <= 0:
                    del pair_freq[pair]

        # 构建新的 word
        new_word = []
        i = 0
        while i < len(word):
            if (
                i < len(word) - 1
                and word[i] == best_pair[0]
                and word[i + 1] == best_pair[1]
            ):
                new_word.append(new_token)
                i += 2
            else:
                new_word.append(word[i])
                i += 1

        new_word_tuple = tuple(new_word)

        # 添加新word的pair频次
        for i in range(len(new_word_tuple) - 1):
            pair = (new_word_tuple[i], new_word_tuple[i + 1])
            pair_freq[pair] = pair_freq.get(pair, 0) + freq

        # 更新 word_freq
        word_freq[new_word_tuple] = word_freq.get(new_word_tuple, 0) + freq


def count_pair_frequencies(
    word_freq: dict[tuple[bytes, ...], int],
) -> dict[tuple[bytes, bytes], int]:
    """统计预分词的频次"""
    pair_freq = {}
    for word, freq in word_freq.items():
        for i in range(len(word) - 1):
            pair = (word[i], word[i + 1])
            pair_freq[pair] = pair_freq.get(pair, 0) + freq
    return pair_freq


def find_best_pair(
    pair_freq: dict[tuple[bytes, bytes], int],
) -> tuple[bytes, bytes] | None:
    """根据频次进行BPE合并，如果频率相同，合并字典序更大的对"""
    if not pair_freq:
        return None
    best_pair = None
    max_freq = -1
    for pair, freq in pair_freq.items():
        if freq > max_freq or (freq == max_freq and pair > best_pair):
            best_pair = pair
            max_freq = freq
    return best_pair


def pre_tokenize(input_path: str, special_tokens: list[str]) -> list[str]:
    """对文本块进行预分词，返回预分词列表"""

    # 预分词阶段可以并行处理
    task = []
    with open(input_path, "rb") as f:
        num_processes = os.cpu_count() or 4
        boundaries = find_chunk_boundaries(f, num_processes, b"<|endoftext|>")

        for start, end in zip(boundaries[:-1], boundaries[1:]):
            f.seek(start)
            chunk = f.read(end - start).decode("utf-8", errors="ignore")
            task.append(chunk)

    num_processes = os.cpu_count() or 4
    with multiprocessing.Pool(processes=num_processes) as pool:
        # 使用 partial 来绑定 special_tokens 参数
        worker = partial(_pre_tokenizer_worker, special_tokens=special_tokens)
        results = pool.map(worker, task)

    # 合并所有结果
    pre_tokenize_list = []
    for res in results:
        pre_tokenize_list.extend(res)
    return pre_tokenize_list


def _pre_tokenizer_worker(chunk: str, special_tokens: list[str]) -> list[str]:
    """对文本块进行预分词，返回预分词列表"""
    if not chunk:
        return []

    result = []

    # 如果没有特殊token，直接用正则分词
    if not special_tokens:
        return re.findall(PAT, chunk)

    # 构建特殊token的正则模式，用于分割文本
    # 需要转义特殊token中的正则特殊字符
    escaped_tokens = [re.escape(token) for token in special_tokens]
    special_pattern = "|".join(escaped_tokens)

    # 使用正则分割，保留分隔符（特殊token）
    parts = re.split(f"({special_pattern})", chunk)

    special_token_set = set(special_tokens)
    for part in parts:
        if not part:
            continue
        if part in special_token_set:
            # 特殊token直接加入结果
            result.append(part)
        else:
            # 非特殊token部分用正则分词
            tokens = re.findall(PAT, part)
            result.extend(tokens)

    return result

from kilo_inplements.bpe_tokenizer_train import run_train_bpe
import pickle
import json
import time
import tracemalloc


def train_bpe_tinystories(tinystories_path, output_path):
    vocab_size = 10000  # 设置词汇表大小
    special_tokens = ["<|endoftext|>"]

    # 开始内存追踪
    tracemalloc.start()
    start_time = time.time()

    vocab, merges = run_train_bpe(
        input_path=tinystories_path,
        vocab_size=vocab_size,
        special_tokens=special_tokens,
    )

    # 记录训练时间和内存
    end_time = time.time()
    current_mem, peak_mem = tracemalloc.get_traced_memory()
    tracemalloc.stop()

    training_time_seconds = end_time - start_time
    training_time_minutes = training_time_seconds / 60
    peak_memory_gb = peak_mem / (1024 ** 3)

    # 将结果保存到输出路径
    with open(output_path, "wb") as f:
        pickle.dump((vocab, merges), f)

    # 统计信息
    # 找出最长的token
    longest_token = max(vocab.values(), key=len)
    longest_token_id = [k for k, v in vocab.items() if v == longest_token][0]

    # 尝试解码最长token
    try:
        longest_token_decoded = longest_token.decode("utf-8")
    except:
        longest_token_decoded = str(longest_token)

    # 检查特殊token
    endoftext_bytes = "<|endoftext|>".encode("utf-8")
    endoftext_id = None
    for token_id, token_bytes in vocab.items():
        if token_bytes == endoftext_bytes:
            endoftext_id = token_id
            break

    # 获取最长的10个tokens
    sorted_tokens = sorted(vocab.items(), key=lambda x: len(x[1]), reverse=True)[:10]
    top_10_longest = []
    for token_id, token_bytes in sorted_tokens:
        try:
            decoded = token_bytes.decode("utf-8")
        except:
            decoded = str(token_bytes)
        top_10_longest.append({
            "id": token_id,
            "token": decoded,
            "length_bytes": len(token_bytes)
        })

    # 构建统计信息
    stats = {
        "training_time_seconds": round(training_time_seconds, 2),
        "training_time_minutes": round(training_time_minutes, 2),
        "peak_memory_bytes": peak_mem,
        "peak_memory_gb": round(peak_memory_gb, 4),
        "vocab_size": len(vocab),
        "num_merges": len(merges),
        "longest_token": {
            "id": longest_token_id,
            "token": longest_token_decoded,
            "length_bytes": len(longest_token)
        },
        "top_10_longest_tokens": top_10_longest,
        "special_token_endoftext_id": endoftext_id,
        "input_file": str(tinystories_path),
        "output_file": str(output_path)
    }

    # 输出统计信息到JSON文件
    stats_output_path = output_path.replace(".pkl", "_stats.json")
    with open(stats_output_path, "w", encoding="utf-8") as f:
        json.dump(stats, f, ensure_ascii=False, indent=2)

    # 打印统计信息
    print("\n" + "=" * 50)
    print("BPE训练统计信息")
    print("=" * 50)
    print(f"训练时间: {training_time_seconds:.2f} 秒 ({training_time_minutes:.2f} 分钟)")
    print(f"峰值内存: {peak_memory_gb:.4f} GB")
    print(f"词汇表大小: {len(vocab)}")
    print(f"合并操作数: {len(merges)}")
    print(f"\n最长token:")
    print(f"  ID: {longest_token_id}")
    print(f"  内容: {repr(longest_token_decoded)}")
    print(f"  长度: {len(longest_token)} 字节")
    print(f"\n<|endoftext|> token ID: {endoftext_id}")
    print(f"\n统计信息已保存到: {stats_output_path}")
    print("=" * 50)

    return vocab, merges, stats

### 2.6 BPE Tokenizer:Encoding and Decoding
上个部分我们实现了训练BPE分词器，可以将文本转换成词汇表和合并列表。

这部分我们要更进一步，能够利用这些词汇表和合并列表，去将文本编码成token IDs，或者从token IDs解码成文本。

#### 2.6.1 Encoding text
这个阶段实际上和BPE训练很相似，只是不需要统计词频。

首先进行预分词，这里步骤完全一样，将text按照正则去拆分成单词列表。

下一步是遍历每个单词，根据合并列表，将优先级最高的合并操作应用到单词上，直到单词不再能被合并为止。

最后就是借助反向词汇表（因为词汇表是id->token的映射），将合并后的token列表转换成id列表。

#### 2.6.2 Decoding text
这一步更简单，只要遍历id列表，根据词汇表，将id转换成token，然后拼接起来就可以了。

```python
import json
from typing import Iterable, Iterator
from kilo_inplements.bpe_tokenizer_train import _pre_tokenizer_worker


class Tokenizer:
    def __init__(
        self,
        vocab: dict[int, bytes],
        merges: list[tuple[bytes, bytes]],
        special_tokens: list[str] = None,
    ):
        if special_tokens is not None:
            for token in special_tokens:
                token_bytes = token.encode("utf-8")
                if token_bytes not in vocab.values():
                    vocab[len(vocab)] = token_bytes
        self.vocab = vocab
        self.merges = merges
        self.special_tokens = special_tokens if special_tokens is not None else []
        # 构建 merge 优先级字典，用于快速查找
        self.merge_priority = {pair: i for i, pair in enumerate(merges)}

    @classmethod
    def from_files(
        cls, vocab_filepath: str, merges_filepath: str, special_tokens: list[str] = None
    ):
        with open(vocab_filepath, "r", encoding="utf-8") as f:
            vocab_raw = json.load(f)
        with open(merges_filepath, "r", encoding="utf-8") as f:
            merges_raw = json.load(f)

        # 转换 vocab: str key -> int key, list[int] value -> bytes value
        vocab = {int(k): bytes(v) for k, v in vocab_raw.items()}
        # 转换 merges: list[list[int]] -> tuple[bytes, bytes]
        merges = [(bytes(pair[0]), bytes(pair[1])) for pair in merges_raw]

        return cls(vocab, merges, special_tokens)

    def encode(self, text: str) -> list[int]:
        # 1. Pre-tokenization
        pre_tokenize_list = _pre_tokenizer_worker(text, self.special_tokens)

        # 2. 构建 token->id 的反向映射
        byte_to_id = {
            token_bytes: token_id for token_id, token_bytes in self.vocab.items()
        }

        ids = []
        for word in pre_tokenize_list:
            # 检查是否是特殊token
            if word in self.special_tokens:
                word_bytes = word.encode("utf-8")
                ids.append(byte_to_id[word_bytes])
                continue

            # 将每个字符转换为单字节的bytes对象
            word_bytes = [bytes([b]) for b in word.encode("utf-8")]
            # 对每个word单独进行BPE合并
            merged_tokens = self._merge_tokens(word_bytes)
            # Encode to ids
            ids.extend([byte_to_id[token] for token in merged_tokens])

        return ids

    def _merge_tokens(self, bytes_tokens: list[bytes]) -> list[bytes]:
        """应用BPE合并规则，按优先级顺序合并"""
        if len(bytes_tokens) <= 1:
            return bytes_tokens

        while True:
            # 找到优先级最高（索引最小）的可合并pair
            best_pair = None
            best_priority = float("inf")

            for i in range(len(bytes_tokens) - 1):
                pair = (bytes_tokens[i], bytes_tokens[i + 1])
                if pair in self.merge_priority:
                    priority = self.merge_priority[pair]
                    if priority < best_priority:
                        best_priority = priority
                        best_pair = pair

            # 如果没有可合并的pair，退出
            if best_pair is None:
                break

            # 合并所有该pair的出现
            new_token = best_pair[0] + best_pair[1]
            new_tokens = []
            i = 0
            while i < len(bytes_tokens):
                if (
                    i < len(bytes_tokens) - 1
                    and bytes_tokens[i] == best_pair[0]
                    and bytes_tokens[i + 1] == best_pair[1]
                ):
                    new_tokens.append(new_token)
                    i += 2
                else:
                    new_tokens.append(bytes_tokens[i])
                    i += 1
            bytes_tokens = new_tokens

        return bytes_tokens

    def encode_iterable(self, iterable: Iterable[str]) -> Iterator[int]:
        for text in iterable:
            ids = self.encode(text)
            for id_ in ids:
                yield id_

    def decode(self, ids: list[int]) -> str:
        # 先拼接所有bytes，再一次性解码，避免多字节Unicode字符被拆分
        all_bytes = b"".join(self.vocab[id_] for id_ in ids)
        return all_bytes.decode("utf-8", errors="replace")
